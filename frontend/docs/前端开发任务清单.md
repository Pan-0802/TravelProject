## 五、与后端同学的交接规则（每完成一个接口）

后端需提供：① URL + 方法 ② 请求 DTO ③ 成功/失败示例 ④ Apifox 验证截图 ⑤ 依赖的 SQL 版本。
前端确认页面联通后标记"联调通过"。**禁止未通知就改字段名、状态码或返回结构。**

接口状态统一为：`待开发 → 后端完成 → 前端接入 → 联调通过 → 回归通过`

## 六、风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 后端接口字段与契约不一致 | 页面取不到值 | 以 `types/api.ts` 为准，先对字段再改页面；改契约要双方确认 |
| 高德 Key 未配置 | 景点搜索不可用 | 页面已做 50300 提示；演示时可只展示本地景点与收藏 |
| 大模型超时/额度不足 | AI 演示失败 | 提前录制 AI 成功视频；页面对 502/504 有明确提示 |
| 本机无 Node | 无法启动前端 | 优先安装 Node LTS（README 第一节） |
| 联调时间被压缩 | 演示翻车 | 用 Mock 模式先保证页面可用，再逐模块替换真实接口 |
